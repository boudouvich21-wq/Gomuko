GoMoKu

Connect-5 Game — Two players, one black and one white.

Your browser does not support Java applets.
⚠️ Note: Java Applets are deprecated in modern browsers (removed in 2018).
Use the Java Applet Runner browser extension or an older browser.
Alternatively, see the GitHub repo for a standalone Java client launcher.

Instructions:
1. Enter your name and click "Enter Arena"
2. Wait for an opponent to join
3. Click a cell to place your stone
4. Get 5 in a row (horizontal, vertical, or diagonal) to win!
